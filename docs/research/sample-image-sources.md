# Studio sample image sources

Pigment includes six modest JPEG derivatives from Wikimedia Commons. The set is selected for legibility at the Studio's default grid: large compositional shapes, clear silhouettes, and deliberate color separation matter more than full-resolution detail. Each source is openly licensed or in the public domain.

Source metadata was queried from Wikimedia Commons' official MediaWiki API. Preserve source-page links and attribution with any redistribution or replacement.
